# Knowledge vault

This project uses a shared Markdown knowledge vault (Obsidian style) at:
{VAULT}

- At the start of every task, read {VAULT}/index.md and follow links to notes that matter for the task.
- When the user tells you a decision, rule, preference, correction or fact, write or update a note in {VAULT}/notes/ (one topic per note, [[wikilinks]] between related notes) and add a one-line entry to {VAULT}/index.md.
- When a decision changes, update the existing note and mark the old value as superseded.
- When the user gives you a source document, save a copy or a full summary in {VAULT}/sources/ and link it from the index.
