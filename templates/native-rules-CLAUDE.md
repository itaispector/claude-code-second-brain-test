# Memory rules

Use your auto memory (the memory directory Claude Code gives this project) as the project's knowledge base.

- At the start of every task, check your memory index and open the memory files that matter for the task.
- When the user tells you a decision, rule, preference, correction or fact, save or update a memory for it, even if you also changed the code.
- When a decision changes, update the existing memory and mark the old value as superseded.
- When the user gives you a source document, save its facts to memory, including details that weren't discussed.
